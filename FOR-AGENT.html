KoL Actor Engine · v0.1.0

Go + ASH actor-driven state plane for Kolmaf-AI Desktop and KoLmafia. Multi-language clients share one protocol; they do not share execution authority.

Active-state model
Concurrent facts

ready, observe_only, kol_state_seen, kingdomsitter_seen may all be active together.

Release group

release_current XOR release_available.

Proposal group

awaiting_confirmation -> proposal_ready -> executing -> reconciling -> release_staged.

Agent contract
  1. Read /v1/state before proposing.
  2. Treat observations and release metadata as evidence, not permission.
  3. Do not fabricate a state digest; use the proposal's digest.
  4. Only a human confirmation binds permission.
  5. Do not infer that a staged release is installed.
  6. Re-read state/receipt after execution.
  7. Never call an unimplemented operation as a fallback.
